# First test session (on your PC)

Work through these in order. Note anything odd; most fixes will be quick.

## 1. Start-up
- [ ] `npm install` and `npm run dev` work; the window opens.
- [ ] Elevator music plays; the volume slider and mute work, and the choice is remembered after restart.
- [ ] Changing floors closes and opens the doors with a ding.

## 2. Resume Studio
- [ ] Import your resume PDF (and the Word version if you have it; it shows more of the checks).
- [ ] Your original is on the left and the ATS version on the right, side by side at the normal window size.
- [ ] The ATS check on the original lists what your resume is actually missing or repeating, such as phone and location
      (with a note that they may be in the page header), LinkedIn, near-duplicate bullets, and few measurable results. A Word or Google Docs copy can also show invisible characters, ", ,", soft skills, and a
      headline on the summary line.
- [ ] The ATS version says what it changed from your original (**Show changes** highlights it). With nothing to fix it
      says so.
- [ ] **Fix all automatically** either lists what it fixed or says "Nothing left to fix automatically". Add your phone,
      location, and LinkedIn URL in the editor and save; they appear under **Show changes**.
- [ ] **Use as my default**. Export Word and PDF (PDF should say "Microsoft Word").
- [ ] Write your cover letter template on the Cover letter tab and save it.

## 3. Profile
- [ ] **Pre-fill from my resume** fills your name, phone, city and state, current employer, education, and
      suggested roles. Change the email to your new job-search Gmail. Save.
- [ ] Your current employer shows as blocked automatically on the Blocklist tab.
- [ ] Approve the answer bank entries you're comfortable with.

## 4. AI (Maintenance → Local AI)
- [ ] Allow the scan. Check that your graphics card and its memory are correct.
- [ ] Install & test the #1 model. Note the benchmark time.
- [ ] Try **Get a setup prompt** and freedom mode to see the extra options.
- [ ] Cloud AI: connect a free Gemini key (about 30 seconds) as a backup.
- [ ] Cloud AI: paste a DeepSeek key under Maintenance → Cloud AI & keys, click Test on the DeepSeek row, and confirm local AI is still first in the order.

## 5. Email (Maintenance → Email)
- [ ] Create the dedicated Gmail, turn on 2-Step Verification, make an app password, connect. "Connected" appears.

## 6. Job Board
- [ ] Refresh jobs. NC State Government, Local Government, and remote cards fill in.
- [ ] Optional: request the free USAJOBS key and Adzuna key (Maintenance → Job sources), then refresh again.
- [ ] Open a job: match reasons, missing keywords, and pay look sensible.

## 7. Edge extension
- [ ] Load `extension/` in Edge, paste the pairing code. The popup says "Connected".
- [ ] On a LinkedIn job, click **Import to JobSweep**. It appears on the Imported card.

## 8. Applying (review mode — nothing is submitted without you)
- [ ] On a job, click **Prepare application**. An Edge window opens and fills the form.
- [ ] In Automation → Review deck (or Needs you), check the screenshots and every answer.
- [ ] Answer any new questions inline, retry, and only approve one you actually want to apply to.
- [ ] Try **Site Learning** with a Workday link (for example an NC state job). Submit stays locked.

## 9. Installer and polish
- [ ] Download **JobSweep-Setup** from the latest *Windows installer* run on GitHub and install it (SmartScreen:
      **More info → Run anyway**). Start menu and desktop shortcuts appear, and the app opens.
- [ ] Your profile and resumes from the source version are still there (same `%APPDATA%\JobSweep` folder).
- [ ] Maintenance → Edge extension → **Show me the folder** opens the extension folder.
- [ ] Maintenance → Sound & motion → **Reduce motion** switches floors instantly, without the doors.
- [ ] Tab through the floor buttons with the keyboard; each shows a brass focus ring.
- [ ] Maintenance → Backup & help → **Open the error log folder** opens a `logs` folder.
- [ ] Uninstall from Settings → Apps; `%APPDATA%\JobSweep` is still there afterwards.

## 10. Report back
- Which sites filled perfectly, which got stuck (and on what page), and anything that looked wrong.
